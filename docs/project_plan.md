# Project status

rashomon-py is in its first public release series. The current public scope is intentionally narrow: L2-regularized logistic and linear regression, Hessian-based ellipsoidal screening, hit-and-run sampling with diagnostics, and stability metrics for coefficients, predictions, ambiguity, discrepancy, and model reliance.

Detailed development notes are kept as local project artifacts rather than public documentation. The public roadmap is expressed through the changelog, issue tracker, and the scope boundaries documented in the user guide.
